# Farm photographs

Put photographs of ADRAH Farms in this folder, then list them in
`src/lib/farm-photos.ts`. Nothing appears on the website until it is in that
list, so a file dropped here by accident is never published.

Before adding one:

- resize to about 1600px on the long edge (a phone photo is 4000px, and nobody
  on mobile data needs that)
- save as `.webp` or `.avif`, under roughly 250 KB
- write a real description of what is in the picture for the `alt` field —
  it is read aloud, word for word, to somebody using a screen reader

**No stock photography.** A picture of somebody else's hens is the first thing a
buyer who knows poultry spots, and it makes every other claim on the site
suspect. The pages are written to look finished with no pictures at all.
